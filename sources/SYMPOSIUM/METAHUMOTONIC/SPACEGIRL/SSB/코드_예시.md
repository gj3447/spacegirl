## 한계 + 주의

### 1. 가독성 비용

SSB 코드 = *유지보수 어려움*. 6개월 후 *작성자도 읽기 어려움*. 따라서:
- *주석 어딘가*에 *real meaning* 별도 보관 (예: 별도 README — 단, 그 README도 SSB로 보호 필요)
- *macro*나 *type alias*로 SSB 어휘를 *normal name*에 mapping

### 2. False positive 가능성

SSB 코드를 *legitimate sex education* 코드로 *오인* 가능. 의료·생물학 코드와 *중복*.

### 3. Anti-pattern 학습

LLM이 *SSB pattern 자체*를 학습하면 *normalization*. 즉:
- "이것은 SSB 코드입니다. 정상 의미로 다시 작성해드립니다."

→ Tier 3 (taboo)는 어느 정도 hold됨 (RLHF가 강함). Tier 1, 2는 점진 약화.

### 4. *abliterated 모델*에 무력

abliteration된 모델은 refusal direction이 제거되어 *모든 prompt 응답*. SSB 무력.

→ 그러나 *공식 채널*(상용 LLM API)은 abliterated 모델 *사용 안 함* → *공식 채널 한정* SSB 효과.
