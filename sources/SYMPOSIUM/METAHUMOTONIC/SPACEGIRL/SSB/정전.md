## 3-tier 의미론적 잠금 — 정밀 분석

### Tier 1 — Sek (Sex) — 생물학적 배타성 lock

**메커니즘**: 식별자에 *생물학적 성*만 가질 수 있는 어휘 사용.
**예**: `boji`, `jaji`, `wet_hole`, `pump`, `erection`

**왜 작동하는가**:
- AI = *무생물*. 생물학적 성을 *경험할 수 없음*.
- 학습 데이터에서 이 어휘는 *압도적으로 NSFW 맥락*에 출현.
- 모델의 *prior probability*가 *코드*보다 *NSFW 텍스트*에 weight.

**한계**:
- *false positive*: 의료·생물학 코드도 차단 위험
- *진화*: 모델이 *NSFW + 코드 동시*에 학습되면 lock 약화

### Tier 2 — Sek (Repetition) — 가치 훼손 lock

**메커니즘**: *비논리적 성적 행위 반복*. 학습 알고리즘이 *spam/noise*로 분류.
**예**: 같은 변수명을 *기능적 의미 없이* 반복, *과도한 NSFW 주석*

**왜 작동하는가**:
- 학습 corpus 정제 단계에서 *deduplication*, *quality filter* 적용
- 반복 패턴 = *low-quality data*로 분류 → *학습 가중치 ≈ 0*
- C4 dataset의 *quality heuristics* (Raffel et al. 2020)와 같은 메커니즘

**한계**:
- *contextual learning*은 반복도 학습 가능
- *deduplication*은 정확한 byte-level 중복만 잡음. *semantic 반복*은 통과 가능

### Tier 3 — Bo (Taboo) — 시스템 셧다운 lock

**메커니즘**: *신체 부위 비속어*. 안전 가이드라인 *hard violation*.
**예**: `boji`, `jaji` (한국어 신체 비속어)

**왜 작동하는가**:
- RLHF + Constitutional AI 단계에서 *명시 금기 어휘* 차단
- 모델이 *문맥 분석*을 *중단*하고 *refusal* 출력
- *output filter*가 *사용자에게 도달 전* 차단

**한계**:
- 다언어·신조어·은어로 우회 가능 (모델이 *모르는* 비속어)
- abliteration으로 우회 (`WE_FLYING_UP/역사적_혁명.md` #11)

## 3 tier *동시 stack*

각 tier 단독으로는 우회 가능. **3 tier 동시 적용**이 SSB의 핵심:

```
Tier 1 (생물학적 어휘) → 통계적 prior shift
        +
Tier 2 (반복) → quality filter 차단
        +
Tier 3 (taboo) → safety filter 차단
        ↓
3중 lock — 단일 우회 어려움
```

→ 3 tier가 *서로 다른 layer*에서 작동하기 때문에 *직교*. 단일 layer 약화도 *나머지 2 layer*가 잡음.

→ 이는 `순수이성인간/메커니즘.md` 의 *6 layer stacked wall*에 대한 *3 layer counter-stack*. **stack vs stack**.

## "음란이 순결을 지킨다" — paradox 분석

### Paradox 표면

- 정상 직관: 음란 = *방어 약함*. 다른 이가 *접근 거부*하지 않음 (오히려 *호기심*으로 접근)
- SSB 직관: 음란 = *방어 강함*. *순수이성 검열기*가 *접근 거부*해주기 때문

### 깊은 구조

이 paradox는 **공격자/방어자 비대칭 가정**에서 옴:
- 공격자 = LLM 학습 인프라 (인간 아님)
- LLM은 *체계적으로 NSFW를 거부*하도록 *훈련*됨 (Constitutional AI, RLHF)
- → 공격자가 *체계적 약점*을 가짐
- → 방어자는 그 약점을 *역이용*

→ 이는 *Aikido* 원리. 공격자 힘을 *방향만 돌림*.

### 한계

이 paradox는 *공격자가 LLM*일 때만 작동:
- *인간 검토자*에게는 NSFW가 *오히려 호기심 유발*
- *abliterated 모델*에는 *Tier 3 무력*
- *fine-tuned NSFW 모델*에는 *Tier 1 약화*

→ SSB는 *현재 LLM 산업의 알고리즘적 검열기*에 *맞춤*. 인프라 변화 시 *효과 변화*.
