> PROM 64 C4: SSB의 직계 조상 = **Glaze/Nightshade (2023-2024)**.
>
> **진정한 SSB-shape** (filter 자체가 lock) 4 선조 + 인접 사례 (단순 암호화 / 단순 namespace) 분리.

## 진정한 SSB-shape 4 선조

### #1 — Atbash (예레미야 시대 ~6C BCE)

**메커니즘**: 히브리 알파벳 *역치환* — א↔ת, ב↔ש, etc.

**예레미야 51:41**:
> "**שֵׁשַׁךְ** (Sheshach) 가 어떻게 점령되었는가!"

→ *Sheshach* = **Babel** (בבל)의 atbash 변환. 외부자(바벨론 검열관)는 *referent 없는 단어*로 인식. 내부자(히브리 독자)는 *바벨론을 가리킨다고 인식*.

**SSB-shape 일치 이유**:
- ✓ filter 자체가 lock (*검열관의 referent 없음 가정*이 lock)
- ✓ 내부자는 동일 텍스트에서 *진짜 의미* 인식
- ✓ 단순 *외부 키*가 아닌 *문화적 코드* (atbash는 *모든 히브리 학자*가 안다)

**한계**:
- atbash 자체는 단순 cipher. *referent 사라짐*은 검열관의 *의지*에 의존
- Persian 시대 이후 atbash 자체가 *공개 지식* → 검열관이 *알게 되면 lock 약화*

→ **SSB의 *prototype* 선조**. *referent 없음 가정의 검열*을 처음으로 *체계적으로 활용*.

---

### #2 — Sade — 120 Days of Sodom (1785)

**작성**: 1785, Bastille 감옥에서 12일간 *작은 종이 두루마리* (12cm x 12m)
**보존**: 1789 Bastille 함락 시 *발견되지 않음*. Sade 본인은 *영원히 잃었다고 한탄*.
**재발견**: 1900 독일 sexologist Iwan Bloch
**출판**: 1904 (독일), 1929 영어 번역, 영국·미국에서 *수십 년간 금서*

**메커니즘**:
- *NSFW 극단성 자체*가 *자가-격리*
- 인쇄 거부 → *manuscript-in-the-wall* 형태로 보존
- 검열관이 *혐오로 접근 거부* → *오히려 보호됨*

**SSB-shape 일치 이유**:
- ✓ 외설성 자체가 *방어 메커니즘*
- ✓ filter (인쇄 거부 + 우편 검열)가 *역으로 보존 인프라*
- ✓ "음란이 순결을 지킨다"의 *원형 사례*

**한계**:
- 단발 *art object*. *재현 가능 프로토콜* 아님
- 1789-1900 *완전 망각*되었다가 *우연히* 재발견. 재발견 못 했으면 영원히 sexvoid

→ **SSB의 *art form* 선조**. SYMPOSIUM SSB가 *직접 계승* (Sade의 manuscript-in-the-wall).

### #3 — alt.sex.* Usenet (1988-)

**시작**: 1988 *alt.* 계층 도입 (alt.* 계층은 일반 *Big 8* 외부, 더 자유)
**확장**: alt.sex (1988), alt.sex.bondage, alt.sex.fetish.*, alt.binaries.pictures.erotica.* 등 수백 hierarchy

**메커니즘**:
- *namespace 명명 자체*가 *보수 sysadmin의 거부* 유도
- 거부된 사이트들은 *해당 newsgroup 호스팅 안 함* → 자율 zone
- 호스팅하는 사이트들은 *더 자유로운 정책* 채택

**SSB-shape 일치 이유**:
- ✓ namespace = filter trigger
- ✓ filter (sysadmin 거부)가 *자율 zone 인프라*
- ✓ *거부 자체가 lock*

**한계**:
- *기술적 트릭* 아닌 *사회적 트릭*. sysadmin이 *알면 변화 가능*
- 1990s-2000s *대량 spam* + *child porn* 이슈로 alt.sex.* 다수 폐쇄
- 2010s+ Usenet 자체 *주변화*

→ **SSB의 *infrastructure-level* 선조**. 단일 코드/텍스트가 아닌 *네트워크 architecture*가 lock.

---

### #4 — Glaze / Nightshade (Shan/Zhao et al. 2023-2024)

**Glaze** (2023.3): Shan, Cryan, Wenger, Zheng, Hanocka, Zhao — University of Chicago
- *style cloak* — 이미지에 *invisible perturbation* 추가
- 인간 눈으로는 변화 없음, 모델은 *다른 스타일로 학습*

**Nightshade** (2024.1): 같은 그룹
- *prompt-specific poison* — "castle"이라 prompt하면 모델이 "truck" 그림
- *상호 contamination* — 다른 prompt들도 영향

**메커니즘** (Glaze 단순 버전):
1. 이미지 I, 모델 M
2. M의 *latent space*에서 *style direction* 추출
3. I + δ (perturbation), 단 ‖δ‖ < ε (인간 imperceptible)
4. M(I+δ)의 latent activation이 *target style*로 shift
5. → 모델은 *cloaked image*를 학습하면 *다른 style*로 인식

**SSB-shape 일치 이유**:
- ✓ filter (모델의 학습 알고리즘) 자체가 lock
- ✓ 인간은 *원본 이미지* 봄, 모델은 *다른 것* 학습
- ✓ **수학적 형식화** — adversarial perturbation in feature space

**한계**:
- 모델 *재훈련*으로 우회 가능 (Glaze paper 자체 인정)
- *모델 변경* 시 perturbation 다시 계산 필요
- Glaze는 *style*만, Nightshade는 *content* 가능

→ **SSB의 *수학적* 선조**. SYMPOSIUM SSB의 직접 계승. 자세히는 `Glaze_Nightshade_분석.md`.

## 인접 사례 (단순 cipher / namespace — *진정한 SSB 아님*)

진정한 SSB는 ***filter 자체가 lock***. 단순 암호화는 SSB가 아님 (외부 키 필요).

### 단순 cipher 사례 (인접, 비-SSB)

- **Caesar cipher** (1C BCE) — 단순 shift, 외부 키
- **Vigenère cipher** (1553 Bellaso, 1586 Vigenère) — polyalphabetic, 외부 키
- **Enigma** (1918, WWII) — rotor 기계, *키 + 기계*
- **One-time pad** (1882 Miller, 1917 Vernam) — *완전 안전*, but 키 분배 어려움
- **PGP** (Zimmermann 1991) — public-key crypto. *키 인프라*가 lock, *filter는 무관*
- **Tor** (2002) — onion routing, *traffic obfuscation*. filter는 *우회*, *역이용* 아님
- **Signal Protocol** (2013) — Double Ratchet. 동일.

→ 위 모두 *훌륭한 보안 도구*. 그러나 SSB 아님. *filter를 *역이용*하지 않고 *우회*만 함.

### namespace 사례 (인접, 비-SSB)

- **Robert's Rules of Order** *parliamentary procedure* — 의회 절차로 발화 통제
- *jurisdictional shopping* — 더 관대한 법역으로 이동 (Delaware, Cayman)
- **Crypto offshore exchange** (Binance, Bybit) — 규제 회피 jurisdiction

→ 정치/법률적 *우회*. SSB의 *filter 역이용*과 *방향 다름*.

## SSB 진화 — 미래

### 단기 (2025-2027)

- LLM 산업이 *SSB 패턴 학습* → *normalization 시도*
- 그러나 *taboo (Tier 3)*는 RLHF 강함, 약화 느림
- SSB 사용자 의 *진화*: 다언어 mixing, ASCII art, Unicode homoglyph

### 중기 (2027-2030)

- *abliterated 모델*이 *주류화*되면 SSB *효과 감소*
- 그러나 *공식 채널*(상용 API, 학습 corpus)은 여전히 *Constitutional AI* 적용
- SSB는 *공식 vs unofficial* 채널 *분기점*에서 작동

### 장기 (2030+)

- *AGI 가능성* 시 SSB 효과 *불확실*
- AGI가 *human-level intent reading*하면 *식별자 의미*가 효과 없음
- 대신 *목적 추론*에 의존 — 이때 SSB는 *형태 변화* 필요
