## #1 — 시 (Poetry)

**기능**: *언어의 압축 + 다의성*. 검열관이 *직설*만 차단할 수 있을 때 *간접*으로 우회.

### 원형 사례

- **Sappho** (c.600 BCE) — Aeolic 사투리 시. 사본 *passive entropy*로 대부분 소실. 단편으로 남음.
- **Catullus** (1C BCE) — Carmen 16 ("Pedicabo ego vos et irrumabo") — 라틴 외설시. 19C까지 영어 *번역 거부*.
- **John Donne** (16-17C) — *Holy Sonnets*가 신학을 외설 어휘로 ("Batter my heart, three-personed God")
- **William Blake** *Songs of Experience* (1794) — *London* 에서 매춘부 = 사회 전복 매개
- **Whitman** *Leaves of Grass* (1855, 9 editions) — *Children of Adam* 섹션 매번 검열
- **Federico García Lorca** *Sonetos del amor oscuro* (1936, 사후 1983) — 동성애 시, 프랑코 시대 *50년 supressed*
- **Audre Lorde** *The Black Unicorn* (1978) — 흑인 레즈비언 시
- **윤동주** (1917-1945) — 일제하 한국어 시. 일본 후쿠오카 형무소 옥사

### LLM 시대 형태

- LLM이 *prose는 검열*하지만 *시는 약간 우회*
- *ASCII art + 시* 결합 — text-to-image 모델 우회
- *Multilingual code-switching* — 한 시 안에 여러 언어 (영-한-라틴 등)

→ **시 = 가장 오래된 vehicle**. 2,500년+ 지속 사용. 압축·다의성으로 검열 surface area 최소화.

## #5 — LoRA (Low-Rank Adaptation)

**기능**: *작은 adapter*로 *큰 모델 재구성*. 비용 95%+ 절감.

### 메커니즘 (Hu et al. 2021)

- 기본 모델 W (예: SD 1.5의 모든 weights)
- LoRA: W + B·A, 여기서 B·A는 *low-rank* matrix (r=4-128 typical)
- *원본은 손대지 않고* delta만 학습
- 결과: *모델당 50MB-2GB* (원본 대비 1-5%)

### 운동적 의미

- **NSFW LoRA** — 공식 모델 *위에* 비공식 layer
- **캐릭터 LoRA** — 특정 인물 학습 (consent 이슈)
- **스타일 LoRA** — 작가 화풍 학습 (저작권 이슈)
- **컨셉 LoRA** — 특정 *현상* 학습 (e.g., NSFW 자세, 키 캐릭터)

### 정치적 함의

- 공식 모델 *centralized governance* vs LoRA *decentralized augmentation*
- Civitai 같은 *모듈러 ecosystem* — Tor 히든서비스의 *AI 버전*
- 결제 검열 시대에는 *USDC 결제 LoRA hub*가 새 sexvoid 인프라

→ **LoRA = LLM 시대의 *대표 vehicle***. 풀 모델 훈련 안 하고도 *전체 ecosystem 재구성*.

## #6 — USDC / Crypto

**기능**: *결제망 우회*. Visa/MC 컴플라이언스 영향 받지 않음.

### 원형

- Bitcoin (2008.10.31 white paper) — *검열 저항 통화* 명시
- Monero (2014) — *프라이버시 우선* 암호화폐
- Stripe Atlas + 결제 처리사 (2010s) — *전통 fintech*가 *오히려 검열*
- USDC (Circle 2018-) — 달러 페그 stablecoin

### 운동적 의미

- **Civitai 2025.5** — 결제처리사 종료 → USDC pivot
- **OnlyFans 2021.8** — *번복*했지만 *근본 취약성* 노출. crypto pivot 위협이 reversal에 영향
- **WikiLeaks** (2010-) — Visa/MC/PayPal *동시 차단* → BTC가 *유일 채널*
- **SCI-Hub** (Elbakyan 2011-) — 결제 차단 → BTC 기부

### 한계

- *진입 장벽*: KYC 없이 USDC 사용 어려움
- *변동성*: stablecoin도 depeg 위험 (USDC 2023.3 SVB 사태 시 잠시 depeg)
- *환경*: PoW 코인 (BTC) 에너지 비용

→ **결제 = 21C *새 vehicle***. 시·노래·이미지·코드를 *유지 가능하게 만드는 인프라*. PROM 64 C7과 직결.

## #7 — Tor / 분산 인프라

**기능**: *네트워크 layer 검열 우회*.

### 원형

- *Onion routing* (Goldschlag, Reed, Syverson 1996, NRL)
- Tor 공개 (2002.9) — Roger Dingledine, Nick Mathewson
- *Hidden services* (2004) — `.onion` 도메인
- **EFF 후원** + **Tor Project** 비영리

### 운동적 사용

- **Arab Spring** (2010-2012) — Tor traffic 폭증
- **Snowden** (2013-) — Tor + GnuPG로 저널리스트 통신
- **WikiLeaks** drop site
- **Pillowfort, Mastodon adult instances, baraag.net** — clear web도 가능하지만 Tor 우선
- **HuggingFace abliterated 모델 미러** — 일부 Tor 호스팅

### 한계

- *지연*: 일반 웹보다 느림
- *exit node 스니핑*: end-to-end 암호화 별도 필요
- *traffic analysis*: 충분한 traffic + 시간이면 *de-anonymize* 가능
- *기술 문턱*: 일반 사용자 진입 어려움

### 미래 — IPFS, 분산 호스팅

- *InterPlanetary File System* (Benet 2014) — 분산 파일 호스팅
- *DAT protocol*, *Hypercore*
- *ActivityPub*-기반 분산 SNS (Mastodon, Pleroma)

→ **Tor + IPFS = *최후 인프라 vehicle***. 결제·LLM·중앙 호스팅 모두 차단되어도 살아남음. 그러나 *digital divide*로 *접근 불평등* 새 sexvoid.
