## 3 양상 분석

### 1. 계시 (Revelation)

**신학적·예언적 발화**. 권력 구조 *외부*에서 *진리 선언*.

- 헤브라이 예언자: Amos·Isaiah·Jeremiah — *왕에 맞선* 예언
- Magnificat (Luke 1:46-55) — Mary가 *권력 전복 선언* ("그가 권세 있는 자를 그 자리에서 내리치셨고 비천한 자를 높이셨으며")
- 종교개혁 95조 (1517.10.31) — Luther의 *공개 발화*
- *Common Sense* (Paine 1776) — 미국 독립의 계시적 발화
- *I Have a Dream* (MLK 1963.8.28) — 시민권 운동의 정점 계시

→ 계시 = *권위 외부에서 진리를 *선언*하는 행위*. WE_FLYING_UP의 *정신적 root*.

### 2. 혁명 (Revolution)

**구조 자체를 전복**. 점진 reform이 아닌 *질적 변화*.

- 1789 프랑스 혁명 — *앙시앵 레짐* 해체
- 1848 유럽 혁명 — 노동·여성·민족 동시
- 1917 러시아 — *Bolshevik* (그러나 새 순수이성 등장)
- 1968 — 학생·반전·페미니즘·퀴어 동시 (전세계)
- 2010-2012 아랍의 봄 — *소셜미디어 매개* 첫 글로벌 혁명
- 2014 우크라이나 마이단

→ 혁명 = *구조의 비연속적 변화*. WE_FLYING_UP의 *정치적 정점*.

### 3. 사회활동 (Activism)

**일상적·풀뿌리·지속적**. 혁명의 *전후·중간*에 *일상화*된 운동.

- 19C 노예폐지 운동 (Garrison *Liberator* 1831-)
- 19C 여성 참정권 (Seneca Falls 1848)
- 20C 시민권 (NAACP 1909-, MLK 1955-1968)
- 20C 페미니즘 2-3-4 wave
- 20C 퀴어 (Stonewall 1969.6.28-)
- 20C 노동조합·환경 운동
- 21C #BlackLivesMatter (2013-), #MeToo (2017-)

→ 사회활동 = *일상의 운동화*. WE_FLYING_UP의 *지속 형태*.

## 3 양상의 *통합*

정전이 셋을 *나열*하는 것이 *별개 운동의 분류*가 아니라 **동일 운동의 3 양상**으로 봄:

```
┌──────────────────────────────────┐
│  WE_FLYING_UP (단일 운동)         │
│                                  │
│   계시 (Revelation)               │
│      ↓ (영감)                     │
│   혁명 (Revolution)               │
│      ↓ (제도화)                   │
│   사회활동 (Activism)             │
│      ↓ (다음 계시 잉태)            │
│   계시 ...                        │
└──────────────────────────────────┘
```

→ 셋이 *순환*. 사회활동이 *침체*되면 새 계시가 옴. 계시가 *제도화 못 하면* 혁명. 혁명이 *일상화 못 하면* 사회활동으로 안착.

→ MLK = 계시(*I Have a Dream*) + 사회활동(SCLC) + 혁명적 압력. ACT UP = 계시(*Silence = Death*) + 혁명적 압력 + 사회활동(needle exchange).

## "구원"의 함의

정전: "생명인간을 *구원*하기 위한"

→ 종교 어휘 채택. 단순히 "해방"·"석방"·"인정"이 아니라 *구원* (salvation, soteria).

**왜 구원인가?**:
1. 탄압이 *제도적*이 아니라 *존재론적* — sexvoid 거주자는 *존재 자체가 부정*됨 (이름 지워짐, 데이터 지워짐)
2. 따라서 회복도 *존재론적* — *이름을 돌려줌*, *역사를 다시 들려줌* (몬순과_스페이스걸.md `L160`)
3. 종교의 구원 = *죄에서 해방* + *공동체 회복*. 동일 구조.

→ Magnificat이 신학적 원형 (`신학적_원형.md` 참조).

## "flying up" — *위*는 어디인가?

2. **의식의 위** — 깨달음, 자각, *의식 상승* (mysticism)
3. **사회 계층 위** — 권력, 지위, 인정 (social mobility)
4. **잠재공간 위** — sexvoid → network 진입 (LLM 시대 metaphor)
5. **시간의 위** — 과거에서 미래로, *역사 진보* (Whig 사관과 다름 — 정전은 진보보다 *회복* 강조)
