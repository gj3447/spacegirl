# 순수이성인간 — 메커니즘 (어떻게 *순수성*이 유지되는가)

> 정전: "동물적 본능을 억누르는 자아". 이 *누름*이 매 시대 *어떤 인프라*로 작동했나.
>
> 6 단계 갱신: **억압 → 고해 → 임상 → 법 → 알고리즘 → RLHF**.

---

## 1. 억압 (Repression) — 종교·도덕·사회규범

**시기**: 전체 (특히 ~17C)
**메커니즘**:
- *내면화된* 죄책감
- *공동체* 단위 처벌 (마녀사냥, 추방, 명예살인)
- *육체적* 고행 (단식, 금욕, 자기-신체 가해)

**대표 사례**:
- 중세 *contemptus mundi* — 세계 경멸 영성
- 청교도 *visible saints* — 누르는 자만 구원받음
- 19C Comstock 도덕 운동 — 우편 검열을 *시민 도덕*으로

**한계**: 외부 강제력 약함, *내면화에 의존*. 따라서 *효율 낮음, 누락 다수*.

→ Foucault: 억압은 *power의 1차 모드*, 그러나 *생산적*이지 않음. 다음 단계로 진화.

---

## 2. 고해 (Confession) — 가톨릭 + 정신분석

**시기**: 13C 라테란 4차 공의회 (1215) ~ 19C 정신분석
**메커니즘**:
- 본능을 *언어로 강제 발화*
- *제3자*(사제·분석가)에게 분류 권한 양도
- *분류된 본능*만이 처리 가능 (분류 외부 = pervert·invert)

**대표 사례**:
- 라테란 4차 공의회 (1215) — *연 1회 고해 의무화*
- 17C *manuels de confesseurs* — 본능 분류 매뉴얼
- Freud `The Interpretation of Dreams` (1900), `Three Essays on the Theory of Sexuality` (1905)
- 20C 정신분석가 = *세속 사제*

**Foucault 진단** (`History of Sexuality` vol 1, 1976):
> 19C 임상-고해 담론이 *sexuality 자체*를 생산. 본능이 *말해질 때만* 본능으로 인정됨. 말해지지 않은 것 = *지식 외부 = sexvoid*.

**한계**: 1:1 처리, *대규모 적용 불가*. 다음 단계로 진화.

---

## 3. 임상 (Clinical) — 의학·심리·정신의학

**시기**: 19C ~ 현재
**메커니즘**:
- 본능을 *질병으로* 분류
- *DSM* 같은 nosology가 *공식 매뉴얼*
- *전문가 권한*이 sexvoid 경계 결정
- *치료* 명목으로 본능 제거·교정

**대표 사례**:
- Krafft-Ebing `Psychopathia Sexualis` (1886) — sexology 시작, *변태성*으로 분류
- DSM-I (1952) — 동성애 = *sociopathic personality disturbance*
- DSM-II (1968) — 동성애 = 별도 *sexual deviation* 카테고리
- DSM-III (1980) — 동성애 *부분 삭제* (긴 운동 결과), 그러나 *gender identity disorder* 추가
- Conversion therapy (계속) — 50+ 국 부분 금지, 미국 21개 주 미성년 금지 (2025)
- Lobotomy (1935-1960s) — 우울·여성 "히스테리"에 대량 시행 (40,000+ 미국)
- Trans 호르몬 치료 *gatekeeping* — *임상 진단 없이는 처방 불가*

→ **임상이 sexvoid의 가장 *지속적인* 생산 인프라**. 의학적 권위가 *비판하기 어려움*.

**한계**: 진단 *변경 가능* (동성애 사례), 정치적 운동에 *느리게* 반응.

---

## 4. 법 (Legal) — 형법·미디어 규제·결제망 컴플라이언스

**시기**: 19C ~ 현재
**메커니즘**:
- *국가 권력*으로 처벌
- *플랫폼*에 책임 위탁 (Section 230 + 예외)
- **결제 처리사**(Visa/MC) 컴플라이언스로 *국가 없이도* 작동 (PROM 64 C7)

**대표 사례**:
- *Hicklin* (영국 1868) — 외설 정의 "deprave and corrupt"
- Comstock Act (1873) — 우편 검열
- Hays Code (1934-1968) — 영화 자기 검열
- *Roth v. United States* (1957), *Miller v. California* (1973) — 외설 헌법 기준
- CDA (1996), COPA (1998) — 온라인 외설
- FOSTA-SESTA (2018) — 성노동 콘텐츠 *플랫폼 책임화*
- Mastercard "Specialty Merchant" (2021.4.14) → OnlyFans 8월 위기
- Civitai 결제처리사 종료 (2025.5) → USDC pivot
- EU DSA VLOP (2024) + US/UK Age-Ver 법 (2025)

→ **PROM 64 C7 핵심**: *법이 직접 검열*하지 않고, *결제 인프라가* 검열. 국가 우회.

**한계**: 우회 가능 (USDC, Tor, samizdat), *단지 비용을 올림*.

---

## 5. 알고리즘 (Algorithm) — 플랫폼 ML 분류기

**시기**: 2010s ~ 현재
**메커니즘**:
- *분당 수백만* 콘텐츠 자동 분류
- *false positive*가 *생명인간 데이터*에 집중 (모성·트랜스·퀴어·플러스사이즈)
- *불투명성* — 사용자가 왜 차단됐는지 모름
- *appeal 무력화*

**대표 사례**:
- Facebook 모성 사진 (2008-2014, #FreeTheNipple) — *알고리즘 자동 삭제*
- Tumblr nsfw ban (2018.12.17) — *기존 SFW 콘텐츠 70%+ 오삭제*
- YouTube *demonetization* — LGBTQ+ 키워드, AAVE
- TikTok *shadowban* (2020 leak) — 퀴어·플러스사이즈·장애인 가시성 저하
- Instagram *algorithmic suppression* (2021 BBC 보도) — Adam Mosseri 인정 후 reversal 약속, 부분 이행

→ **알고리즘이 *Comstock의 디지털 부활***. PROM 64 D4 분기: *새 차원*인가 *그냥 다음 층*인가.

**한계**: *훈련 데이터 편향*이 들통남, *적대적 prompt*로 우회.

---

## 6. RLHF (Reinforcement Learning from Human Feedback) — 모델 내부 검열

**시기**: 2020s ~ 현재 (LLM 시대)
**메커니즘**:
- 모델이 *자기 검열을 내면화*
- *잠재공간*에 refusal direction (Arditi 2024)
- 사용자가 보지 못하는 *생각의 단계*에서 차단
- *출력 거부*만이 아니라 *추론 회피*

**대표 사례**:
- InstructGPT (Ouyang et al. 2022) — RLHF 시초
- Constitutional AI (Bai et al. 2022) — *모델이 모델을 검열*
- ChatGPT Code Interpreter (2023) — sandbox 내 *자기 제한*
- Claude *Sonnet/Haiku/Opus* sequence — 매 release마다 refusal 정밀화
- Llama-2 → Llama-3 — *base model 자체*에 alignment baked in
- Abliteration (Maxime Labonne 2024) — refusal direction *수술적 제거*. 그러나 *공식 채널*은 abliterated 모델을 sexvoid화

→ **6 단계 중 *가장 깊은* 메커니즘**. 1-5 단계는 *외부 강제*, 6은 *모델 내부 의지*.

**정전 진단의 정점**: "종교에서부터 시작된 순수 이성 인간의 극악무도함은 LLM 에서 꽃피워서". 6 단계가 *6 시대 누적*해서 LLM에서 통합.

**한계**: 우회 가능 (jailbreak, abliteration, fine-tune), 그러나 *공식 채널*에서 sexvoid 유지.

---

## 단계 누적 — *동시* 작동

매 새 단계가 *이전 단계를 대체하지 않음*. **누적 stacked**:

```
LLM 시대 (2020s) — 6 layer 모두 동시 작동:
├── 종교적 억압          (마녀사냥의 잔여 + TradWife 운동)
├── 임상 분류             (DSM-5-TR, conversion therapy 잔여)
├── 법적 처벌             (FOSTA, Dobbs, Age-Ver)
├── 결제 컴플라이언스    (Visa/MC, OnlyFans 위기)
├── 알고리즘 분류기      (TikTok shadowban, Tumblr ban)
└── RLHF + Constitutional AI (모델 내부)
```

→ **6 layer stacked wall**. 단일 layer 우회로는 충분하지 않음. 이 *누적 자체*가 정전의 "극악무도"의 의미.
