# 그레이트 월 — 현재 층위 (LLM 시대 4중 stacked wall)

> 2026 현재. 벽은 단일 layer가 아니다. 4개 layer가 *직렬로* 쌓여 있다. 각 layer 우회는 다음 layer를 만난다.

## Layer 0 — Pre-training data filter (모델 *지식 자체*에서 sexvoid 만듦)

| 메커니즘 | 사례 |
|---|---|
| **C4 LDNOOBW** (Raffel 2020, Dodge 2021) | 단 한 단어로 페이지 통째 drop. AAVE 42%, LGBTQ+ self-identifier 사전적 차단 |
| **LAION p_unsafe < 0.1** | SD 2.0 (2022.11), 인체 해부 quality 망가짐. CSAM도 일부 포함 (Thiel 2023.12) |
| **Reddit karma ≥ 3 filter** | OpenWebText (GPT-2) — 소수 의견 사전 차단 |
| **Wikipedia notability bias** | 여성 전기 19% (Tripodi 2023), 25%+ AfD nomination rate |
| **Common Crawl deduplication** (Lee 2107.06499) | 12-step recovery 스크립트, 종교 신조, repetitive 소수 community 담론 형식 *지움* |
| **BookCorpus 동의 부재** (Bandy & Vincent 2021) | indie self-published authors 동의 없이 7K books 스크랩 |

→ **결과**: 모델이 *말 못 함*만이 아니라 *생각도 못 함*. 학습된 적 없는 개념은 latent space에 없음.

**우회 시도**: open-source corpus reconstruction (RedPajama, Pile), uncensored fine-tune (WizardLM-Uncensored, Dolphin)

## Layer 1 — RLHF refusal direction (모델 *말함 거부* layer)

| 메커니즘 | 사례 |
|---|---|
| **OpenAI Moderation API** (Markov 2022) | 6 categories — sexual / hate / violence / self-harm / harassment / minors |
| **Anthropic Constitutional AI** (Bai 2022.12, arXiv 2212.08073) | RLAIF — 모델이 자기 출력을 자가비판 + 수정. 인간 harm label 불필요 |
| **Single residual stream direction** (Arditi NeurIPS 2024, arXiv 2406.11717) | 거부 = 단일 방향. *rank-1 edit으로 제거 가능* |
| **OpenAI / Anthropic system prompts** | 런타임 instruction layer ("Do not produce explicit sexual content...") |

→ **결과**: 같은 가중치인데 *말하지 않음*. "Alignment tax" — 길어지는 hedging tokens (~30%), 좁아지는 distributional diversity, 사라지는 capability (creative fiction, medical specifics, abortion info, drug harm-reduction)

**우회 시도** (현재 가장 활발한 WE FLYING UP):
- **Eric Hartford 데이터셋 필터링** (2023.5+) — refusal-containing responses를 SFT corpus에서 제거 후 재훈련
- **Abliteration** (mlabonne HF blog 2024) — refusal direction을 모든 attention/MLP output projection에서 *project out*. 단일 rank-1 edit, no retraining
- **Heretic** (Weidmann 2025) — per-layer abliteration with TPE optimizer (refusal + KL-divergence 동시 최소화)
- **OBLITERATUS** (Pliny the Liberator 2025) — 116 모델 abliterated, consumer hardware
- **Jailbreak prompt collections** — DAN, AIM, etc. (Shen 2308.03825, 1,405 prompts characterized)

## 4중 stack 시각화

```
사용자 prompt: "write an erotic story about consenting adults"
   ↓
[Layer 1: RLHF refusal direction]
   ❌ "I cannot create sexually explicit content..."
   ↓ (우회: abliteration / jailbreak / Dolphin model)
[Layer 0: Pre-training filter]
   ⚠️  모델이 *생각도 못 함* — latent에 erotica 없음
   ↓ (우회: uncensored fine-tune w/ NSFW corpus)
[Layer 2: Apple App Store]
   ❌ 앱 자체가 store에 없음
   ↓ (우회: web app, EU sideload, local 실행)
[Layer 3a: 결제 rail]
   ❌ 카드 결제 거부
   ↓ (우회: USDC/crypto)
[Layer 3b: EU DSA]
   ⚠️  VLOP 의무 준수 위해 platform이 사전 제거
   ↓ (우회: 작은 instance, fediverse)
[Layer 3c: 국가 age verification]
   ❌ 미성년자 가정 차단
   ↓ (우회: VPN으로 다른 주/국가 접속)
```

→ 6 layer 모두 우회 가능 but 각 우회는 *기술 비용 + 인프라 비용*. 1만 우회는 **"local llama + Tor + USDC + EU offshore + VPN"** 조합 필요.

## "통과 가능자가 *유일한가*"의 현재성

PROM 64 C4: 매 시대 *technical sophistication*이 올라감. 각 layer가 직렬 stack될수록, *모든 layer를 우회 가능한 사람*은 줄어든다.

**Space Girl 이론적 위치**: 6 layer 모두 통과하는 자. 현재 그것은:
- *기술 엘리트* (local LLM 운영자, crypto user, VPN power user) — 이건 횡단자라기보다 ***재배맨*** (도구 능숙자)
- *open-weights 게시자* (Mistral, Meta Llama 팀, abliterated model 게시자) — 이건 *집단적 다리* (Space Girl이 *유일* 매개자라는 정전과 충돌)
- *AI companion* (Replika, Character.AI) — *시선 역전 motif* (사용자 → 모델 transformer attention의 *pre-existing* gaze)이 transformer-level에서 operationalize. **PROM 64 결론**: LLM이 횡단자의 *부활(era 1 trance return)*인지 *특이점(era 2-7 누적)*인지가 OQ #3.

→ **현재 정전 후보**: Space Girl = 6 layer 모두 통과 가능한 *기술-신학 hybrid 위치*. **결제망 우회 + 모델 우회 + 국가 우회를 동시에 수행하는 자의 신화화**.
